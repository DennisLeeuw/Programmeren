Een systeembeheerder krijgt niet altijd geldige informatie terug.

Pas daarom foutafhandeling toe.

Eisen:
\begin{itemize}
\item Gebruik minimaal \'e\'en try/catch.
\item Als een computer niet bereikbaar is, mag het script niet volledig stoppen.
\item Toon een duidelijke foutmelding met Write-Warning.
\item Ga verder met de volgende computer.
\end{itemize}
