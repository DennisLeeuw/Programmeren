Voorzie minimaal twee functies van comment-based help.

Gebruik minimaal de volgende onderdelen:
\begin{itemize}
\item .SYNOPSIS
\item .DESCRIPTION
\item .PARAMETER
\item .EXAMPLE
\item .OUTPUTS
\end{itemize}

Controleer je documentatie met:
\begin{lstlisting}[language=bash]
Get-Help Get-ComputerInformation -Full
\end{lstlisting}
