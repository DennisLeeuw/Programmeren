De tweede functie die we maken is:
\begin{lstlisting}[language=bash]
Get-ComputerStatus
\end{lstlisting}
Deze functie verzamelt informatie over de status van een computer.

Verzamel minimaal:
\begin{itemize}
\item Hoeveelheid geïnstalleerd RAM-geheugen.
\item Hoeveelheid vrije schijfruimte op de systeemschijf.
\item De uptime van de computer.
\end{itemize}

Eisen:
\begin{itemize}
\item Gebruik een parameter voor de computernaam.
\item De parameter moet meerdere computernamen kunnen accepteren (array).
\item De parameter moet verplicht zijn.
\item Gebruik parametervalidatie om lege invoer te voorkomen.
\item Gebruik een foreach om alle opgegeven computers te verwerken.
\end{itemize}
