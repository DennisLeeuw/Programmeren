Maak van minimaal twee functies een Advanced Function.

Zorg dat de functies ondersteuning bieden voor:
\begin{itemize}
\item -Verbose
\item -Debug
\end{itemize}

Gebruik in je functies:
\begin{itemize}
\item Write-Verbose om aan te geven welke actie wordt uitgevoerd.
\item Write-Debug om tijdens het uitvoeren informatie over de werking van de functie te tonen.
\end{itemize}

Test dit met:
\begin{lstlisting}[language=bash]
Show-ComputerReport -Verbose
Show-ComputerReport -Debug
\end{lstlisting}
