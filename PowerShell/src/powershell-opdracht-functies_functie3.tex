Tot slot is er een functie nodig die de verzamelde gegevens op als output geeft. We noemen de functie
\begin{lstlisting}[language=bash]
Show-ComputerReport
\end{lstlisting}

Eisen:
\begin{itemize}
\item Gebruik de eerder gemaakt functies
\item Maak een overzichtelijke uitvoer.
\item Gebruik Write-Output voor de resultaten.
\item Zorg dat de informatie per computer herkenbaar is.
\end{itemize}
