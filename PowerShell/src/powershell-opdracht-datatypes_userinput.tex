
Maak een script waarin de gebruiker de volgende gegevens kan invoeren:

\begin{itemize}
\item Naam van de medewerker.
\item Computernaam.
\item Hoeveelheid RAM-geheugen in GB.
\item Aantal processorkernen.
\item Of de computer een laptop is (ja/nee).
\end{itemize}

Sla iedere invoer op in een eigen variabele.

Let op: `Read-Host` levert standaard tekst (String) op. Zorg ervoor dat numerieke gegevens ook daadwerkelijk als getallen worden opgeslagen.
