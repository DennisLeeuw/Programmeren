Het programma moet:
\begin{itemize}
\item gebruikmaken van de Python-module `csv`;
\item gebruikmaken van de Python-module `json`;
\item het CSV-bestand lezen van stdin;
\item de inhoud van iedere regel controleren;
\item alleen `FAIL`-meldingen selecteren;
\item de geselecteerde gegevens bewaren in een Python-lijst;
\item de lijst omzetten naar JSON;
\item wegschrijven naar `resultaat.json` en deze automatisch aanmaken;
\item JSON netjes leesbaar formatteren met bijvoorbeeld `indent=4`.
\end{itemize}
