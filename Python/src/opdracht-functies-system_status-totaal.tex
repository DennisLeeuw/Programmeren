Uiteindelijke willen we weten wat de totaal status van een systeem is. We gaan een functie toevoegen die aangeeft hoe het met een systeem gesteld is.

Maak een functie:
\begin{lstlisting}[language=Python]
def bepaal_systeemstatus(cpu_status, memory_status, disk_status):
\end{lstlisting}

Deze functie bepaalt de algemene status van de computer.

De regels zijn:
\begin{description}
\item[Systeem OK] Alles is OK
\item[Systeem heeft aandacht nodig] E\'en of meer onderdelen zijn Waarschuwing
\item[Systeem Kritiek] E\'en of meer onderdelen zijn Kritiek
\end{description}
