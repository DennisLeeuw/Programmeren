Je programma moet minimaal de volgende functies bevatten:
\begin{enumerate}

\item Computernaam
\begin{lstlisting}[language=Python]
def get_computer_name():
\end{lstlisting}

Deze functie geeft de naam van de computer terug. De functie moet de computernaam teruggeven met \textbf{return}.

\item Besturingssysteem
\begin{lstlisting}[language=Python]
def get_operating_system():
\end{lstlisting}

Deze functie geeft informatie terug over het gebruikte besturingssysteem.

\item CPU-gebruik
\begin{lstlisting}[language=Python]
def get_cpu_usage():
\end{lstlisting}

De functie moet het huidige CPU-gebruik ophalen. Het resultaat moet worden teruggegeven door middel van \textbf{return}.

\item Geheugengebruik
\begin{lstlisting}[language=Python]
def get_memory_usage():
\end{lstlisting}

De functie moet het percentage gebruikt geheugen teruggeven.

\item Schijfruimte
\begin{lstlisting}[language=Python]
def get_disk_usage():
\end{lstlisting}

De functie moet het percentage gebruikte schijfruimte teruggeven.

\end{enumerate}
