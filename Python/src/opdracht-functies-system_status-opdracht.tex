Maak een Python-programma met de naam:
\begin{lstlisting}[language=bash]
system_checker.py
\end{lstlisting}

Het programma controleert verschillende onderdelen van de computer.

De volgende informatie moet worden gecontroleerd:
\begin{enumerate}
\item Computernaam
\item Besturingssysteem
\item CPU-gebruik
\item Geheugengebruik
\item Vrije schijfruimte
\end{enumerate}

Gebruik hiervoor bijvoorbeeld de Python-module `psutil`.

Installeer deze indien nodig.
