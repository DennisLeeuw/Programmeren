Maak een hoofdprogramma waarin je de verschillende functies aanroept.

De uitvoer moet ongeveer lijken op:

\begin{verbatim}
====================================
       SYSTEM HEALTH CHECK
====================================

Computernaam : PC-ICT-023
Besturingssysteem : Windows 11

CPU-gebruik       : 23%   [OK]
Geheugengebruik   : 74%   [Waarschuwing]
Schijfgebruik     : 52%   [OK]

====================================
SYSTEEMSTATUS: WAARSCHUWING
====================================
\end{verbatim}

De daadwerkelijke waarden zijn natuurlijk afhankelijk van de computer waarop het programma wordt uitgevoerd.
